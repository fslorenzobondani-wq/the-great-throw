# CLAUDE.md · The Great Throw

## What it is
A browser game for the Vibe Coding final project (Elisava). Players throw flags at a spinning circus wheel with faceless, censored world leaders. Laptop = target screen, phone = controller (paired after picking the countries). Real data: petrol prices, exchange rates, Brent, weather, live cams.

## About me
Lorenzo — fashion editor and creative director, not a developer. Explain changes in plain words.

## Stack
HTML, CSS, JS in a single `index.html`. No build step. GitHub Pages.

## Rules
- No text inside the game except the title logo: icons, flags, colours, numbers only.
- Characters are named after nations, never people; no words put in politicians' mouths.
- Soundtrack: `audio/soundtrack.mp3`, played with Web Audio (real visualiser, tape-stop on crash). Lorenzo chose to host the file in the repo knowing it is public.
- No API keys or personal data in the repository.
